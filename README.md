# Ioannis Vlachos — personal website

Academic website at [ioannisvlachos.com](https://ioannisvlachos.com), built with Quarto and published through GitHub Pages.

Use [Pages CMS](https://app.pagescms.org) to manage blog posts, research, **Code** entries, profile details, and the CV through browser forms. Work on **main**; saving can publish changes after a successful build. New blog posts start as drafts.

Readers can [subscribe by RSS](https://ioannisvlachos.com/subscribe.html) to all updates or to Blog, Research, or Code individually.

- **[Editing guide](docs/EDITING.md):** connect, write, preview, and update the CV.
- **[Setup and maintenance](docs/CMS-CONFIG.md):** local commands, configuration caveats, and connection status.
